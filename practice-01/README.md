## 4. Задание 1. Один файл — две среды выполнения

### Результаты вывода

| Среда | Тип document | Значение |
|-------|-------------|----------|
| **Node.js (терминал)** | undefined | не определено |
| **Браузер (консоль)** | object | DOM-объект |

### Объяснение различий

Глобальный объект `document` представляет собой **модель DOM (Document Object Model)**, которая существует только в среде браузера для управления веб-страницей. 

В **Node.js** (серверной/консольной среде) браузерное DOM-дерево отсутствует, поэтому переменная `document` не определена (`undefined`).

## 5. Задание 2. Исследование типов и преобразований

| Выражение | Ожидание | Фактическое значение | Тип | Объяснение |
|-----------|----------|----------------------|-----|------------|
| `"8" + 2` | `"82"` | `"82"` | `string` | Бинарный оператор `+` при наличии строки выполняет конкатенацию, преобразуя число 2 в строку |
| `"8" - 2` | `6` | `6` | `number` | Оператор `-` не определён для строк, поэтому строка `"8"` преобразуется в число 8 |
| `Number("8") + 2` | `10` | `10` | `number` | Явное приведение строки даёт 8, затем обычное сложение чисел |
| `"12" > "3"` | `false` | `false` | `boolean` | Сравнение строк происходит лексикографически: символ `"1"` имеет меньший код, чем `"3"` |
| `12 === "12"` | `false` | `false` | `boolean` | Оператор `===` проверяет тип без автоматического приведения |
| `Number("")` | `0` | `0` | `number` | Пустая строка при явном преобразовании даёт `0` |
| `Number("text")` | `NaN` | `NaN` | `number` | Текст не может быть преобразован, поэтому результат `NaN` |
| `Boolean("false")` | `true` | `true` | `boolean` | `Boolean()` преобразует любую непустую строку в `true` |
| `typeof null` | `"object"` | `"object"` | `string` | Особенность реализации: `null` — примитивный тип, но `typeof` возвращает `"object"` |
| `typeof NaN` | `"number"` | `"number"` | `string` | `NaN` — специальное числовое значение |

## Дополнительное задание. Вариант А (`progress-input.js`)

Реализован разбор и валидация строкового ввода для расчета прогресса задач.

### Ответ на теоретический вопрос:
Недостаточно просто вызвать `Number(input)` и проверить, что результат не отрицателен, по следующим причинам:
1. **Пустые строки и пробелы:** `Number("")`, `Number(" ")` и `Number(null)` в JavaScript возвращают `0`. Простая проверка на неотрицательность пропустит пустой ввод как валидное число `0`.
2. **Спецсимволы:** `Number("Infinity")` даст значение `Infinity`, которое больше нуля, но не является допустимым количеством задач.
3. **Дробные числа:** Проверка знака пропускает дробные строки вроде `"2.5"`, хотя количество задач может быть только целым.
